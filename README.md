# SmartScan Go

SmartScan Go is a student project prototype exploring a smartphone-based supermarket self-checkout experience.

## Features

- Sample supermarket products
- Manual product-code entry
- Shopping cart with quantity controls
- Automatic subtotal and estimated tax calculation
- Demo checkout and digital receipt
- Exit-verification code demonstration
- Responsive layout for desktop and mobile screens

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` with the Live Server extension.

## Limitations

This is a front-end demonstration. It does not process real payments, scan actual barcodes, connect to a supermarket inventory, or provide production-grade exit verification.

All products and prices are sample data.
